# FedCloud-FL

Federated fraud detection under non-IID client distributions, with FedAvg/FedProx training and validation-based decision-threshold evaluation.

**[Read the complete project narrative](fedcloud-fl/docs/COMPLETE_PROJECT_NARRATIVE.md)** — report-ready background, architecture, methodology, mathematical definitions, dataset, experiments, verified results, limitations and references.

For setup, testing, synthetic demonstration and code layout, see the [application README](fedcloud-fl/README.md).

The saved nine-run results are from a sequential federated simulation. A clean Windows Python 3.12 test suite passed 13 tests; independent reproduction of the archived full-data predictions remains pending.
